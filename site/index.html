NOTHING separates identity, claims, evidence, verification events and procedures so a status can be inspected instead of simply trusted.

The public prototype currently contains synthetic demo data only.

01

Identity

A stable project-level reference such as NTH-000001.

02

Evidence

What source or material was considered, when it was collected, and its integrity information.

03

Verification

Which claim was evaluated, using which procedure, with what result and scope.

04

Lifecycle

Historical events remain visible when a later event supersedes an earlier one.

DESIGN PRINCIPLE

Collect less. Prove more.

A valid record is not automatically a truthful record. The prototype deliberately exposes the chain behind a result and avoids a universal trust score.
