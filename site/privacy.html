NOTHING Browser Extension & Registration Web App

This page describes the current prototype's data boundary.

Browser extension

The extension inspects the active page only after you press the inspection button. It can read the page title, URL, hostname, canonical URL, public site name metadata and public description metadata needed to create a draft.

Draft data can be stored locally in browser storage so it survives opening the registration page. The extension does not request browsing-history access, cookies, passwords, seed phrases or private keys.

Registration

When a user submits a registration, the deployed NOTHING service may store the submitted business or brand information needed for the identity record. Registration does not itself establish independent verification; claims can remain self-claimed until a verification procedure is completed.

Wallets and payments

When payment is enabled, a compatible wallet provider is used to approve a transaction. NOTHING does not ask users to enter a wallet seed phrase or private key. The service verifies payment through its server-side chain adapter rather than trusting a browser-reported transaction result.

Current prototype status

The extension can run in demo/activation-gated mode. Production payment, retention, deletion procedures, jurisdiction-specific privacy terms and any on-chain NFT issuance must be finalized before commercial launch.
